# AliAli —— 只看 AI 圈

仿哔哩哔哩网页版首页 / 视频页的 AI 圈视频站。所有视频实时同步自 bilibili 上 **AI 博主** 与 **AI 公司官方账号** 的投稿。

![首页预览](docs/screenshot.jpg)

## 下载桌面客户端（Windows）

到 [Releases](https://github.com/Edoardo-Zhang/aliali/releases/latest) 下载 `AliAli-Setup-x.y.z.exe`（约 78 MB）：

- 安装包里**自带完整的 AliAli 服务和一份数据快照**，装完直接可用，**不依赖任何服务器**
- 首次运行 Windows 会提示「未知发布者」（未做代码签名），点 **更多信息 → 仍要运行** 即可
- 客户端数据（收藏、历史等）保存在 `%APPDATA%\AliAli`
- 快捷键：Alt+←/→ 后退前进、F5 刷新、F11 全屏；右键可在浏览器打开 bilibili 原视频

> 想跑网站版？见下面的「运行」——需要一台**常驻机器**（Node 18+，零依赖）：服务端要每 10 分钟同步 B 站数据、写缓存、推 SSE，所以静态托管（GitHub Pages 等）跑不了它。

## 运行

```bash
cd aliali
npm start        # 等价于 node server.js，需要 Node 18+，零依赖
```

打开 http://localhost:8520 。首次启动需要约 2~3 分钟完成第一轮同步（页面会显示进度），之后数据缓存在 `data/cache.json`，重启秒开。

## 桌面客户端（Windows）

客户端工程在 `client/`（Electron）。安装包里自带完整的 AliAli 服务和一份数据快照，安装后直接可用，不依赖服务器。

```bash
cd client
npm install          # 首次需要；国内网络建议设置 ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm run release      # 生成图标 → 打包 dist/AliAli-Setup-x.y.z.exe → 发布到 ../downloads/
```

- 发布后网站顶栏的“下载客户端”会显示版本、大小和下载按钮（接口 `/api/client`，文件 `/download/AliAli-Setup-x.y.z.exe`）
- 发新版：改 `client/package.json` 的 `version` 后重新 `npm run release`
- 网站上线后可在 `client/client.json` 填 `remote`（如 `https://你的域名`），客户端会优先连线上站点，连不上自动用内置服务
- `npm run smoke` 可做一次无界面自检
- 客户端快捷键：Alt+←/→（或鼠标侧键）后退前进、F5 刷新、F11 全屏；右键菜单可在浏览器中打开 bilibili 原视频
- 客户端数据（收藏、历史等）保存在 `%APPDATA%\AliAli`

## 数据来源与实时更新

- 白名单在 [config.js](config.js)：`official` = AI 公司 / 机构官方号，`creator` = AI 博主；`filter: true` 的账号会按 AI 关键词过滤标题
- 服务端每 **10 分钟** 同步一次所有白名单账号的最新投稿，并批量刷新播放 / 弹幕 / 点赞 / 投币 / 收藏数
- 有新视频时通过 SSE 推送到首页（顶部出现“AI 圈有 N 个新视频”提示）
- 详情页的播放量等数据每 60 秒刷新，“xx 人正在看”每 30 秒刷新
- 详情页只允许打开白名单账号（含联合投稿成员）的视频，其他视频会返回 403

## 功能

- **首页**：视差头图、顶栏（搜索历史 + 热搜、头像面板、动态 / 收藏 / 历史弹层）、频道栏、主色轮播、推荐网格、换一换、无限滚动、稍后再看、吸顶导航
- **视频页**：自研播放器（下方详述）、弹幕发送（带颜色）、真实弹幕列表（随进度高亮、点击跳转）、真实评论（最热 / 最新，含表情）、UP 主卡片 + 关注、视频选集（多 P）、接下来播放
- **播放器**：服务端代理 bilibili 的 MP4 视频流（免登录最高 720P，支持拖动 / Range），前端原生 `<video>`
  - 倍速 0.5x–2x、清晰度切换（保留进度）、音量 / 静音、画中画、宽屏、网页全屏、全屏
  - 弹幕与进度同步渲染（滚动 / 顶部 / 底部），可调不透明度、字号、显示区域、速度
  - 断点续播（“已为您定位至…”）、播完自动连播（可取消）
  - 如果浏览器不响应或拒绝全屏请求（例如某些内嵌浏览器），会自动退回网页全屏
  - 快捷键：空格 播放/暂停、← → 快退/快进 5 秒、↑ ↓ 音量、F 全屏、D 弹幕开关、M 静音、[ ] 调速、Esc 退出网页全屏
  - 取流失败时自动退回 bilibili 外链播放器

已知限制（bilibili 对未登录访问的限制）：画质最高 720P；评论区每个视频只开放前几条，页面底部会给出去 bilibili 查看全部的链接。
- **个人空间** `/space`（顶栏头像 → 个人中心，或顶栏的动态 / 收藏 / 历史）：
  - 动态：关注的 UP 主新投稿 + 我的转发，右侧推荐关注
  - 关注：关注列表 + AI 圈推荐关注；已关注按钮点击后需确认才会取消关注
  - 收藏：多收藏夹，新建 / 重命名 / 公开私密 / 删除，取消收藏，播放全部
  - 历史记录：按今天 / 昨天 / 近一周 / 更早分组，显示“看到 xx:xx / 已看完”进度，可搜索、删除、清空、暂停记录
  - 稍后再看：全部播放、移除已观看、一键清空
- **分享转发**：复制 AliAli 链接 / bilibili 原链接 / 嵌入代码，转发到动态（可写转发理由），分享到微博 / QQ 空间（使用 bilibili 原链接）
- **弹幕开关与屏蔽**：发送栏开关或 D 键开关弹幕；弹幕设置里可按滚动 / 顶部 / 底部 / 彩色屏蔽，或添加屏蔽词（自己发的弹幕不会被屏蔽）
- **一键三连**：长按点赞约 1.5 秒，三个按钮同时出现蓄力环，蓄满后点赞 + 投 2 币 + 收藏并播放点亮动画；中途松手则取消；短按为普通点赞
- **投币 / 收藏弹窗**：1 / 2 枚硬币选择、同时点赞；多收藏夹、新建收藏夹
- 快捷键：`Q` 点赞（长按三连）、`W` 投币、`E` 收藏

点赞 / 投币 / 收藏 / 关注 / 历史 / 评论都保存在本地浏览器（localStorage），不会写回 bilibili。

## 目录结构

```
server.js            零依赖 Node 服务：静态托管 + 定时同步 + API + SSE
config.js            收录白名单（AI 公司官方号 / AI 博主）
public/              网页前端（首页 / 视频页 / 个人空间）
client/              Electron 桌面客户端（自带服务与数据快照）
downloads/           客户端安装包与 latest.json（供网站展示下载按钮）
data/cache.json      运行时缓存（首次启动自动生成）
```
